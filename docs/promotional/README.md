# Promotional drafts and screenshot provenance

This directory contains historical launch drafts, not current product documentation or approved release announcements. Features, versions, privacy claims, platform requirements and installation steps in individual drafts may be outdated. Check the [current README](../../README.md) and [0.1.0 validation status](../releases/0.1.0.md) before reusing them.

- `screenshots/output/` contains rendered promotional **mockups** produced from `screenshots/mockup.html` by `screenshots/capture.js`. They are not captures of the running plugin and are not real-test evidence.
- `screenshots/real/` contains earlier application captures. They do not establish the appearance or behavior of the current 0.1.0 build.
- Current real acceptance evidence is recorded separately in the local directories identified in the [version status](../releases/0.1.0.md#finding-or-reproducing-evidence). Those generated files are ignored by Git and must be shared separately.

No promotional capture script or mock service was run for this documentation update. The [other promotion folder](../promotion/README.md) has the same draft status.
