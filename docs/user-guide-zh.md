# 使用指南 — 0.1.0

[English](user-guide-en.md) · [README](../README-zh.md) · [版本与验证状态](releases/0.1.0.md)

## 配置模型

打开 **设置 → Intelligence Assistant → LLM**。“提供商”子页用于配置连接，“模型”子页用于管理发现的模型、启用状态和默认选择。

1. 选择提供商。兼容 OpenAI 的网关使用 Custom，并填写基础 URL。
2. 选择 Obsidian 钥匙串中的凭据。某些本地/自定义服务无需密钥，取决于服务本身。
3. 测试连接并检查返回的模型，确认模型已启用且具有所需能力。
4. 设置默认聊天模型。RAG 使用的嵌入模型需单独选择。
5. 开始长任务前，先发送一个简短的真实聊天请求。

模型发现、普通聊天、工具调用、图片输入和嵌入是不同能力。模型列表请求成功，不代表这些能力都已验证。不同连接可能暴露相同的模型名称，请同时核对提供商标签。

本版本的提供商类型包括 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter、Ollama、SAP AI Core 和 Custom。实际模型是否可用，由配置的服务决定。

### SAP AI Core

把完整 Service Key JSON 保存到 Obsidian 钥匙串，在 SAP 提供商配置中选择该密钥，并设置资源组（通常为 `default`）。AI API 地址默认读取 `serviceurls.AI_API_URL`，也可覆盖。连接测试用于发现运行中的部署，然后选择支持的部署/模型。旧的明文 Service Key 会迁移为密钥引用，先前删除的配置无法自动重建。

本次发布准备未调用真实 SAP 租户；Ollama 也未纳入当前真实验收。Manifold 的结果不能作为这两者的验证结论，详见[验证记录](releases/0.1.0.md)。

| LLM | 提供商与模型 |
| MCP | 配置、连接及检查 MCP 服务器 |
| 工具 | 内置、MCP、OpenAPI 和 CLI 工具源 |
| RAG | 索引、检索、过滤、评分和网络搜索 |
| 提示词 | 可复用系统提示词 |
| 智能体 | 预设、模型策略、权限、预算、记忆和写入设置 |

可以点击 Tab 或使用键盘导航。“通用”保留宿主的可搜索设置控件。不同子页使用同一份配置；“工具”中出现 MCP，并不代表另一份服务器配置。

## 聊天、引用和图片

从功能区或命令面板打开 AI 聊天，选择模型，在 Chat 模式进行普通对话。需要发送笔记或文件夹内容时添加引用。图片输入需要模型和服务支持；移除附件只改变待发送请求，不会删除原文件。

复制、保存和插入按钮操作实际回复。插入或保存前请确认目标及当前编辑器。提供商错误、输出限制和 Stop 可能留下不完整回复；回复保存在会话里，不等于任务已完成。

## 智能体与写入

智能体组合系统提示词、模型策略、工具权限、预算和可选知识功能。四个专家预设是供选择的配置，不是四个并行工作者。

模型策略：

- **默认**：使用配置的默认模型。
- **跟随聊天**：使用聊天视图当前选择的模型。
- **固定**：使用智能体自身选择的模型。

应选择支持工具调用的模型。兼容 OpenAI、Anthropic、Gemini 和 Ollama 的适配器分别实现对应的原生工具协议；不应期待任意无工具能力的模型自动回退到文本解析。

内置知识库写入工具返回提案。关闭“自主写入”时，需要审阅并应用提案卡片；待确认的提案不是已保存文件。智能体启用“自主写入”且任务经过宿主授权后，可在运行中应用支持的提案，让后续工具使用实际文件。提示词中的一句话不会授予该设置或新权限。自动应用失败时，可能保留手动提案供审阅。

配置的 CLI、MCP 和 HTTP 工具可以直接产生副作用，不会因为被智能体调用就自动变成知识库写入提案。集成使用对应进程/服务的访问权限；应只添加可信定义，并授予任务需要的工具。

## 停止与续跑

1. 在智能体运行中点击 **Stop**。
2. 检查工具记录和实际文件，尤其留意结果不确定的外部操作。
3. 在同一会话发送 `Continue.`。重载 Obsidian 后也使用这个流程。

宿主保留原始目标、已识别的工具限制、有界的成功工作证据，以及待处理/结果不确定的动作。重读较早的文件，不会使未完成工作的边界自动倒退。本次运行计数和上次运行计数具有独立范围。

续跑是利用已保存证据发起的新运行，不是自动日志回放、语义完成保证或外部修改“恰好一次”的保证。证据被截断、源文件变化或外部调用结果不确定时，应先检查实际状态。

需要限制工具时，用普通顶层文本和准确名称，例如 `Use only read_file;`、`No tools.` 或 `Only use the read_file tool.`。语法支持范围有限，无法识别的显式限制会按关闭权限处理。引用示例、引用块和代码块中的内容属于数据，不会授予权限。一个独立的新任务会开始新的限制范围。

长任务需要合适的智能体步数和输出预算，并应要求可观察的产物。提供商限制可能截断生成；推理模型可能把部分输出预算用于推理。插件不会通过悄悄提高预算或关闭推理，把不完整回复标成成功。

## RAG、记忆和网络搜索

**RAG**：选择嵌入模型、配置纳入/排除内容，再在 RAG 页构建索引。索引存于本地，但嵌入请求使用选定服务。启用增量嵌入后，后续文件事件可以更新索引。更换嵌入模型或索引规则后，按需重建。检索/上下文限制及可选模型评分决定进入请求的内容；引用链接不是答案正确的保证。

**记忆**：每个智能体可选择无记忆、短期或长期记忆。无记忆会阻止该次运行读取和写入记忆，不会删除已经保存的记忆。短期记忆保留在当前插件会话内，长期记忆会持久化保存；启用记忆可能增加模型或嵌入调用。请检查所选模式和保留数量。

**网络搜索**：在 **RAG → 网络搜索** 配置。后端包括 Google、Bing、SerpAPI、Tavily、SearXNG、Brave、Qwant、Mojeek。部分后端需要密钥或服务器地址；查询启发式也可能决定不搜索。第三方可用性及访问限制不同。旧的 DuckDuckGo/Yahoo/Yandex 选择会迁移到 SearXNG，需要配置可用端点；它们不是当前后端。

## 数据存储与凭据

插件目录为 `<库配置目录>/plugins/intelligence-assistant/`，通常位于 `.obsidian` 下：

- `data.json`：当前设置文档，包含配置、提供商定义、提示词和智能体；受 SecretStorage 管理的密钥值会在保存前移除。
- `data/conversations/`：会话内容及执行元数据。
- `data/agent-runs/`：JSONL 事件日志，用于检查记录，不是崩溃回放引擎。
- 其余 `data/` 子目录：依据配置保存模型/MCP 缓存、用量、记忆和 RAG 索引。
- `data.json.bak`：替换前保存的上一份设置文档。

旧的 `config/user/settings.json` 等分散设置文件会迁入当前文档，在成功保存后移除。升级替换三个程序文件时应保留这些应用数据。

提供商/API 密钥、SAP Service Key、受支持的网络搜索凭据字段和 OpenAPI 认证值保存在 Obsidian SecretStorage；设置记录密钥名称。在另一台设备上可用的密钥，与配置文件是否同步，是不同问题。CLI/MCP 环境设置和任意其他配置字段不会自动作为秘密管理。分享设置前应检查并脱敏。

提示词、包含的笔记/图片、检索上下文和已启用的记忆可发送到模型提供商；嵌入文本发送到嵌入服务；网络搜索接收基于原始输入的查询。外部工具接收参数，并可能具有各自的存储、网络和文件访问行为。本插件不加密本地会话/索引文件，其他已启用的 Obsidian 插件共享宿主环境。

## 排查问题

| 现象 | 检查项 |
|---|---|
| 可连接但没有可用模型 | URL、认证、发现/启用的模型及模型所需能力 |
| 空回复或输出被截断 | 服务错误/结束原因、输出预算、推理使用、上下文大小和提供商限制 |
| 工具调用后文件不存在 | 返回的是待确认提案、已应用结果还是错误；检查实际路径 |
| 智能体无法调用工具 | 全局工具源、智能体权限、准确任务限制及工具源重载后的当前绑定 |
| Continue 重复或描述不确定的工作 | 查看记录和产物，验证被省略的证据及不确定外部副作用 |
| 搜索失败 | 后端凭据/地址和服务方限制；较早审计中 Qwant 无密钥路径返回过 403 |
| 提交可复现问题 | 提供插件/Obsidian 版本、提供商/模型、任务、步骤和已脱敏日志，不要附带密钥及私有笔记 |
