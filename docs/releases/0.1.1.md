# 0.1.1 — cumulative release notes

Version 0.1.1 includes the complete 0.1.0 change list together with the source-review corrections and Verification Gate fixture repairs. The canonical user-facing entry is in [CHANGELOG.md](../../CHANGELOG.md#011); its “Included changes from 0.1.0” section preserves all five groups from the [0.1.0 record](0.1.0.md#included-changes).

The version metadata in package.json, package-lock.json, manifest.json and versions.json is synchronized to 0.1.1. The minimum remains Obsidian Desktop 1.13.0. UI layout, styling and locale text remain unchanged by this patch.

## Automatic release notes

The existing [publisher](../../.github/workflows/ci-cd.yml) uses `scripts/release-notes.js` to extract the manifest version's changelog entry and append installation instructions, assets, verification scope and the actual CI source/run identity. Missing or empty entries and a version mismatch fail the generation step. Release notes are passed through `body_path`, so publication no longer uses only a generic installation template.

Preview the exact release body locally:

```bash
node scripts/release-notes.js /tmp/intelligence-assistant-0.1.1-notes.md
```

A normal main/master push can automatically publish an untagged version after the publisher's required checks. This local preparation does not create a tag, push source, replace 0.1.0 assets or establish that 0.1.1 has been published. Check [GitHub Releases](https://github.com/qwai-tech/obsidian-plugin-intelligence-assistant/releases) for publication.
