# 0.1.0 preparation branch

This revision promotes the plugin version from 0.0.23 to 0.1.0. It synchronizes
package.json, package-lock.json, manifest.json and versions.json, retaining
Obsidian 1.13.0 as the minimum application version. Application source, UI,
styles, translations and dependencies are unchanged by this version revision.

The previous complete live release gate belongs to version 0.0.23. Its report
and certificate remain unchanged under
`test-results/release-prep-0.0.23-2026-11-05/`. They must not be relabeled as a
new full 0.1.0 live release gate. This version revision is checked through
version consistency, lint, both type checks, development/production builds,
bundle comparison, local deployment and an actual Obsidian upgrade/reload check.
Generated evidence for those checks is local under
`test-results/version-0.1.0-2026-11-05/`.

Only `codex/release-prep-0.1.0` is pushed. No main/master update, version tag,
GitHub Release or formal publication is included. The version commit includes
`[skip ci]` because this repository's every-push workflow contains mock-based
tests and the current instruction prohibits mocks. Before a later formal
publication, explicitly run the applicable release checks for that candidate
and use a publish-authorized commit/workflow.

Ollama remains excluded and SAP AI Core receives no live call.
