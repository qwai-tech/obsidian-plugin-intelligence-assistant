# Historical plans and reports

The dated documents under `plans/`, `specs/` and `reports/` record earlier designs, implementation steps and test runs. They can contain retired paths, unfinished proposals, mock-based workflows or results that apply only to the build tested at the time. Retaining a plan does not mean every proposed behavior is implemented.

Use the [documentation index](../README.md), [current architecture](../architecture/overview-en.md), [testing guide](../reference/testing.md) and [0.1.0 validation status](../releases/0.1.0.md) for current contracts and evidence scope.
